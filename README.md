# Seventy Coffee — сайт

Одностраничный сайт Seventy: specialty-обжарка и три кофейни в Алматы.
Чистые HTML, CSS и JS, без сборки. Все библиотеки лежат в `vendor/`, поэтому сайт не зависит от CDN.

## Запуск

Сайт использует ES-модули, поэтому открывать его нужно через любой локальный сервер, а не двойным кликом по файлу:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

Деплой: любой статический хостинг (GitHub Pages, Vercel, Netlify). Просто загрузите папку целиком.

## Структура

| Путь | Что это |
|---|---|
| `index.html` | разметка и тексты |
| `css/site.css` | дизайн: цвета, шрифты, вёрстка |
| `js/main.js` | плавный скролл, появление блоков, курсор, «открыто сейчас», отсчёт до события |
| `js/scene.js` | 3D: чашка, пар, зёрна, облёт камеры, смена света |
| `images/` | фото. `hero-static.webp` — статичная картинка для слабых телефонов |
| `vendor/` | Three.js r170, GSAP 3.12 + ScrollTrigger, Lenis 1.1 |

## Что поменять

- **Телефон WhatsApp, часы работы, дата события** — объект `CONFIG` в начале `js/main.js`.
- **Цены** — в `index.html` ищите `<span class="price">цена</span>`.
- **Фото** — блоки с классом `ph` (штриховка и подпись, какое фото нужно). Замените блок на
  `<figure class="ph-real"><img src="images/имя.webp" alt="описание"></figure>`.
- **Ноты вкуса лотов** — у Бразилии Cerrado ноты взяты с упаковки, у остальных лотов это типичные ноты региона, их стоит сверить.

## 3D и производительность

- Сцена собрана из примитивов в коде, без файлов моделей, поэтому почти ничего не весит.
- На телефоне: меньше полигонов и зёрен, без теней, плотность пикселей не выше 1.5.
- Сайт сам замеряет FPS: если тормозит, упрощает картинку, а если всё равно тормозит, показывает статичное фото чашки.
- Без WebGL или со слабым устройством сразу показывается `images/hero-static.webp`.
- `prefers-reduced-motion` отключает вращение, плавный скролл и анимации.
- Перерисовать статичную картинку: открыть `/?poster` и сохранить `window.__poster` (PNG) в `images/hero-static.webp`.
