# Seventy Coffee — сайт

Одностраничный сайт сети кофеен Seventy Coffee (Алматы). Чистые HTML/CSS/JS, без сборки.

- Открыть локально: `index.html` в браузере.
- Контакты, Instagram, часы работы: объект `CONFIG` в начале `script.js`.
- Фото: см. `images/README.md`.
- 3D-пачки кофе — CSS 3D + JS (крутятся сами, вращаются мышкой/пальцем), без внешних библиотек.

Деплой: любой статический хостинг (GitHub Pages, Vercel, Netlify).
